# Feature

Implement a focused feature in this Flutter project.

## Workflow

1. Inspect the existing app structure in `lib/`.
2. Prefer small, readable changes aligned with Material Design conventions.
3. Update any relevant tests for the new behavior.
4. Run validation using the check command.

## Commands

```bash
fvm flutter analyze
fvm flutter test
```

## Purpose

Use this command when adding a small feature or UI behavior without broad refactoring.
