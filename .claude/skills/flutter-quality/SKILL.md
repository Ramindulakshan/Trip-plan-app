# Flutter Quality

Use this skill when reviewing or improving code quality in the Flutter project.

## Goals

- keep code clean and consistent with Dart/Flutter conventions
- reduce duplication and unnecessary complexity
- ensure maintainability without broad refactors
- preserve app stability and correctness

## Workflow

1. Inspect the implementation and identify quality issues.
2. Make the smallest fix that improves clarity or correctness.
3. Keep naming, structure, and widget composition consistent.
4. Validate with analysis and tests.

## Validation

```bash
fvm flutter analyze
fvm flutter test
```
